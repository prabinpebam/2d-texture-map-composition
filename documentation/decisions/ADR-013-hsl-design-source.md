# ADR-013: HSL Picker Design Source

- Status: Blocked visual fidelity only
- Evidence: `documentation/evidence/m1/SPIKE-008-hsl-design-source.md`

Do not invent or claim exact visual parity without the approved source. The
future picker may implement the closed accessible behavior, keyboard model, and
numeric color contract, but visual token mapping and parity review remain blocked
until source states are available.
